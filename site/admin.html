    Usuários e acessos

    Marque as páginas e filiais de cada usuário. A alteração é salva sozinha e vale no próximo carregamento da página dele. Admin sempre tem acesso a tudo.

    O usuário nasce só com Propostas liberada e já pode entrar. Marque os outros acessos na tabela. Anote a senha para passar à filial: ela não aparece de novo.

    Aparelhos

    Com a trava ligada, cada login só entra por aparelho liberado aqui (o admin fica de fora). Aparelho novo aparece como "Aguardando" e a pessoa vê só "Aguardando liberação". O nome (✏️) é só para você saber qual é qual. "Desconectar" tira o aparelho do sistema na hora. Quem já estava logado quando a trava foi criada entra liberado.

    Erros do sistema

    Erros que aconteceram no navegador de cada pessoa nos últimos 30 dias. O mesmo erro na mesma página fica numa linha só, mesmo vindo de várias pessoas ou versões: soma em "Vezes" e "Ver os registros" mostra cada um. Só o admin vê esta lista.
